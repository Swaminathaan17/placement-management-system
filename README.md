# 🎓 Placement Management System

A modern **Full-Stack Placement Management System** built with **React.js, Node.js, Express.js, and JSON Server**. The application helps administrators efficiently manage student records, sections, and placement eligibility through an intuitive dashboard with analytics.

---

## ✨ Features

- 🔐 Secure Admin Login
- 👨‍🎓 Student Management (Add, Edit, Delete)
- 🏫 Section Management
- 📊 Interactive Dashboard with Analytics
- 📈 Placement Eligibility Checker
- 📋 Search & Filter Students
- 📤 Export Student Data to Excel
- 🌙 Dark Mode Support
- 📱 Responsive User Interface

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Swaminathaan17/placement-management-system.git
```

### 2. Navigate into the Project

```bash
cd placement-management-system
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

## ▶ Running the Project

### Start the Backend

```bash
cd backend
npm start
```

### Start the Frontend

```bash
cd frontend
npm start
```

The application will open at:

```
http://localhost:3000
```
